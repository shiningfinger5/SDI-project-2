This is an application that fetches and filters data from the TVMaze api.

The criteria for fetching and filtering is that the application will only grab TV shows that contain whatever genre you request, as well as having an average TV rating at, or above, '8.0'

It contains 3 route paths, 1 for the default homepage ('/'), one for the About page ('/about') and one for the actual TV details and summary ("/show/:showID").
